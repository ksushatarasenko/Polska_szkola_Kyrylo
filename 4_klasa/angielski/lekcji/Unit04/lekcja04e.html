📘 Lekcja 3e – Określniki a/an, some, any. Konstrukcja there is/are – zdania pytające i krótkie odpowiedzi. Ćwiczenia gramatyczne i w mówieniu.

🎯 Цель урока

Ученик:

  • понимает разницу между a/an – some – any
  • строит утверждения, отрицания и вопросы
  • даёт короткие ответы
  • описывает комнату по картинке
  • ✅ wiem kiedy użyć a / an
  • ✅ wiem kiedy użyć some / any
  • ✅ potrafię zadać pytanie Is there…? / Are there…?
  • ✅ potrafię odpowiedzieć Yes, there is / No, there aren’t
🔹 Шаг 1 – a / an

Объяснение простое:

  • a → перед согласным звуком
  • an → перед гласным звуком

❗ не буква, а звук!

🔹 Шаг 2 – some / any
Is there…? / Are there…?

1️⃣ There’s an/a sofa in the living room. -> ✅ a sofa

Sofa начинается с согласного звука /s/ → используем a.

❌ an sofa — нельзя, потому что не гласный звук.


2️⃣ There are some/any chairs in the bedroom. -> ✅ some chairs

Это утвердительное предложение (There are…).

В утверждениях во множественном числе используем some.


3️⃣ Is there a/an desk in the room? -> ✅ a desk

Desk начинается с согласного звука /d/ → используем a.


4️⃣ There aren’t some/any pillows on the bed. -> ✅ any pillows

Это отрицательное предложение (There aren’t…).

В отрицательных предложениях во множественном числе используем any.

1️⃣ There are ___ paintings on the wall. -> ✅ some paintings

Почему?

  • множественное число (paintings)
  • предложение утвердительное → используем some

2️⃣ There isn’t ___ armchair in the kitchen. -> ✅ any armchair

Почему?

  • armchair — единственное число
  • начинается с гласного звука /ɑː/ → используем an

3️⃣ There aren’t ___ books on the desk. -> ✅ any books

Почему?

  • books — множественное число
  • предложение отрицательное → используем any

4️⃣ There is ___ bookcase in my bedroom. -> ✅ a bookcase

Почему?

  • bookcase — единственное число
  • начинается с согласного звука /b/ → используем a

🔹 Главное правило для детей

  • ✔ some → в утверждении
  • ✔ any → в вопросах и отрицаниях
